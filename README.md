# jungtaejoon.github.io

- `/` forwards to [Slop](https://jungtaejoon.github.io/slop/) (source: [jungtaejoon/slop](https://github.com/jungtaejoon/slop)).
- `404.html` forwards old `/slop-lab/...` links to `/slop/...`.
- `.well-known/assetlinks.json` lets the Slop Android app (io.github.jungtaejoon.slop) open the site full screen.
  After the first Google Play upload, add the "App signing key certificate" SHA-256 from Play Console to it.
